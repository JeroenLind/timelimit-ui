# codingrules

Alle JavaScript-functies die worden aangeroepen vanuit externe .js-bestanden, moeten ook gedefinieerd zijn in diezelfde .js-bestanden - nooit in inline HTML scripts.

Alle CSS-klassen die in HTML worden gebruikt, moeten ook gedefinieerd zijn in de CSS file. Voeg een test toe die controleert of alle klassen in de HTML ook in de CSS bestaan.

CSS-klassen die in HTML worden gebruikt, moeten éénmalig gedefinieerd zijn in de externe CSS file. Vermijd inline CSS definities die kunnen conflicteren met externe stylesheets.

Alle teksten en knoppen op een UI moeten ruim voldoene contrast met de achtergrond hebben zodat ze altijd goed zichtbaar zijn

When working with an API to the timelimit server, also keep the API documentation updated at all times. Only add verified content. Verify it using the source code of the official timelimit server
