# testaftercodechange

When you are finished making a change/implementing feature always run all unit test of the dashboardV2. It is not allowed to finish a task when there a tests failing. Even when they seem not related to the change.

Make it clear to the user that you start this testing phase

A task cannot be set to done without all unit tests of the dashboard passing

As the project is already contains lots of tests, expect the test to run for a while (2 minutes)
