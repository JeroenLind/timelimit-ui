# Mock Data Structure Documentation

This document describes the structure of mock data generated by the `MockDataGenerator` class for testing the TimeLimit backend API.

## Overview

The mock data generator creates reproducible, seed-based test data for:
- Families (parent-child relationships)
- Users (parent and child accounts)
- Devices (parent and child devices)
- Categories (time limit categories)
- Apps (installed applications)
- Time limit rules
- Used time items
- Child tasks
- Crypto keys (Curve25519, DH)
- U2F data

## Configuration

Mock data generation is controlled by the following environment variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `MOCK_DATA_SEED` | 42 | Seed for reproducible data generation |
| `MOCK_FAMILY_COUNT` | 1 | Number of families to generate |
| `MOCK_CHILD_COUNT` | 2 | Number of child users per family |
| `MOCK_DEVICE_COUNT` | 3 | Number of devices per family |
| `MOCK_CATEGORY_COUNT` | 3 | Number of categories per child |
| `MOCK_APP_COUNT` | 10 | Number of apps per device |

## Data Relationships

### Family Hierarchy

```
Family
├── Parent User (type: "parent")
│   └── Parent Device
└── Child Users (type: "child")
    └── Child Devices (1-N per child)
```

### Category Hierarchy

```
Category
├── Belongs to Child User (childId)
├── May have Parent Category (parentCategoryId)
├── Has Apps Assigned (categoryApp)
├── Has Time Limit Rules (rules)
├── Has Used Time Items (usedTimes)
└── Has Child Tasks (tasks)
```

### Device Relationships

```
Device
├── Belongs to Family (familyId)
├── Owned by User (currentUserId)
├── Has Installed Apps (apps)
└── May have Public Key (Curve25519)
```

## Generation Logic

### Seed-Based Reproducibility

The `MockDataGenerator` uses a seed value to create deterministic random values:

1. Seed is hashed with SHA-256 to create a base hash
2. Each random value is generated by:
   - Incrementing a counter
   - Combining the base hash with the counter
   - Hashing the combination
   - Using the hash to generate the random value

This ensures that the same seed always produces the same data.

### UUID Generation

UUIDs are generated as deterministic 8-4-4-4-12 format strings using the random generator.

### Password Hashing

Parent passwords are hashed using bcrypt with cost factor 12:
- Primary hash: `hash_password(password)`
- Second hash: `hash_password(password + second_salt)`

### Crypto Key Generation

- **Curve25519**: Generated using `generate_keypair()` for device public keys
- **DH Key**: Simulated secp256r1 key for password encryption

## Example Usage

```python
from app.services.mock_data import MockDataGenerator
from app.core.config import settings

# Create generator with default seed
generator = MockDataGenerator()

# Generate a family
family = generator.generate_family()

# Generate users for the family
parent_user = generator.generate_user(
    user_id="user_parent123",
    family_id=family["family_id"],
    user_type="parent"
)

# Generate devices
device = generator.generate_device(
    device_id="device_abc123",
    family_id=family["family_id"],
    user_id=parent_user["id"]
)

# Generate categories
category = generator.generate_category(
    category_id="cat_abc123",
    child_id="user_child1"
)

# Generate complete family data
family_data = generator.generate_family_data()
```

## Notes

- All timestamps are in milliseconds since Unix epoch
- All time values are in milliseconds
- Empty strings indicate "not set" or "no value"
- `null` values indicate optional fields not provided
- The `version` field in sync data is used for CRDT conflict resolution
