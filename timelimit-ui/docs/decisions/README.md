# Decision records

One short file per decision: `<ID>-<slug>.md`, written from `TEMPLATE.md`.
The IDs are the ones in `docs/plan/implementation-plan.md` section 3 (K, Q, R, S, T, W). A new decision
gets a new ID and a record in the same commit that applies it. A test checks that every decision row
of the plan has a record.
